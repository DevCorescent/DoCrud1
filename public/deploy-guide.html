How to Deploy Updates to Production

Follow these steps every time you push a code change and want it live on docrud.com.

1
AWS Console

Log in to AWS

Open aws.amazon.com and click Sign in to the Console.

Choose Root user and enter the registered root email address, then the password.

Use root login credentials (keep these secure — do not share).
2
Region

Select Europe (Stockholm) Region

In the top-right corner of the AWS Console, click the region dropdown and select Europe (Stockholm) — eu-north-1.

3
EC2

Go to EC2 → Instances

In the search bar type EC2 and open it. From the left sidebar click Instances.

Find the instance named docrud and select it.

4
Connect

Connect via EC2 Instance Connect

With the instance selected, click the Connect button at the top. Choose the EC2 Instance Connect tab and click Connect.

A browser terminal will open directly — no SSH key needed.

5
Terminal

Navigate to the Project

In the terminal, run:

cd ~/docrud
6
Terminal

Pull Latest Code from GitHub

Fetch and apply the latest changes from the main branch:

git fetch origin git reset --hard origin/main
7
Terminal

Build the App

Compile the Next.js application. This takes 2–5 minutes:

npm install npm run build
Wait for "✓ Compiled successfully" before moving to the next step.
8
Terminal

Restart the App with PM2

Apply the new build and restart the running server:

pm2 restart all

Verify the app is running:

pm2 status
Status should show online. The site is now live at docrud.com.
